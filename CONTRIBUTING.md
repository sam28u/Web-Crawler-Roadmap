# Contributing

Thanks for your interest in improving this project.

We welcome documentation improvements, roadmap updates, examples, and project guidance that make the material more useful and accurate.

## How to contribute

1. Fork the repository.
2. Create a feature branch for your change.
3. Make focused updates that align with the project goals.
4. Keep the content clear, practical, and professional.
5. Open a pull request with a short summary of what changed and why.

## What to include

- Clear explanations for technical concepts
- Practical examples that can be applied in real projects
- Accurate and up-to-date references to tools, libraries, and architecture patterns
- Ethical and legal guidance when discussing web crawling or data collection

## Documentation standards

- Prefer concise, readable writing
- Use headings and bullet lists where they improve clarity
- Keep examples realistic and easy to follow
- Avoid using scraped or copyrighted material without permission
- Call out legal and ethical constraints when discussing crawling or access to data

## Pull request guidelines

- Keep each PR focused on one topic or improvement
- Include enough context for reviewers to understand the change
- Mention any assumptions, trade-offs, or limitations
- Ensure links and examples are valid

## Code of conduct

Please be respectful, constructive, and collaborative. We aim to keep discussions focused on improving the project and helping others learn.

## Legal and ethical reminder

This project is educational and should be used responsibly. Do not encourage or provide guidance for unauthorized access, abuse, or bypassing protections on systems you do not own or have explicit permission to test.
